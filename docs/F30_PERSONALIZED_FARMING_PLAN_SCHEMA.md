## 1. Schema Overview

Every agricultural research roadmap generated by F30 is represented as a structured JSON object adhering to this canonical schema. This structure ensures transparent evidence citation, chronological milestone tracking, fertilizer calculations, and direct F24 reminder integration.

---

## 2. JSON Schema Definition

```typescript
export interface PersonalizedFarmingPlan {
  // Plan Identity
  id: string; // UUID v4
  title_bn: string; // e.g. "ব্রি ধান২৮ বোরো মৌসুমে চাষাবাদ পরিকল্পনা"
  title_en: string; // e.g. "BRRI dhan28 Boro Season Cultivation Roadmap"
  created_at: string; // ISO 8601 UTC timestamp
  updated_at: string; // ISO 8601 UTC timestamp
  version: number; // Schema version (e.g. 1)
  is_saved: boolean; // Flag indicating if saved in IndexedDB

  // Crop & Field Snapshot
  field_profile: {
    division?: string;
    district?: string;
    upazila?: string;
    season: 'boro' | 'aman' | 'aus';
    variety_id: string; // e.g. "brri_28"
    variety_name: string; // e.g. "BRRI dhan28 (ব্রি ধান২৮)"
    duration_days: number; // Total crop duration (e.g. 140)
    cultivation_method: 'transplanted' | 'direct_seeded';
    start_date: string; // "YYYY-MM-DD" (Transplanting date or Sowing date)
    estimated_harvest_date: string; // "YYYY-MM-DD"
    land_area: {
      amount: number; // e.g. 33
      unit: 'decimal' | 'bigha' | 'acre' | 'hectare';
      standard_decimals: number; // Normalized area in decimals
    };
    current_stage_id?: string;
  };

  // Executive Summaries
  overview: {
    summary_bn: string; // Concise written answer in Bengali
    summary_en: string; // Concise written answer in English
    voice_summary_bn: string; // Spoken audio transcript in simple spoken Bengali
    immediate_action_bn: string; // What the farmer should do today
    immediate_action_en: string;
  };

  // Research Traceability & Sources
  research_metadata: {
    query_text: string;
    research_date: string; // "YYYY-MM-DD"
    research_quality: 'official_verified' | 'multi_source_consensus' | 'limited_evidence' | 'conflicting';
    sources: Array<{
      id: string;
      name_bn: string;
      name_en: string;
      institution: string;
      url: string;
      revision_year: string;
      access_date: string;
      trust_tier: 1 | 2 | 3;
      relevant_topics: string[];
    }>;
  };

  // Chronological Roadmap Stages
  roadmap: Array<{
    stage_id: string; // e.g. "stage_tillering"
    stage_name_bn: string; // e.g. "সক্রিয় কুশি গজানো"
    stage_name_en: string; // e.g. "Active Tillering"
    start_day_offset: number; // e.g. 16 DAT
    end_day_offset: number; // e.g. 35 DAT
    start_date: string; // Computed "YYYY-MM-DD"
    end_date: string; // Computed "YYYY-MM-DD"
    status: 'completed' | 'current' | 'upcoming';
    key_focus_bn: string;
    key_focus_en: string;
    tasks: Array<{
      task_id: string; // e.g. "task_urea_topdress_1"
      title_bn: string;
      title_en: string;
      description_bn: string;
      description_en: string;
      due_date: string; // "YYYY-MM-DD"
      category: 'fertilizer' | 'water' | 'weeding' | 'pest_scouting' | 'harvest';
      is_essential: boolean;
      can_remind: boolean;
      reminder_active: boolean;
      reminder_id?: string; // F24 remindersStore record ID
    }>;
  }>;

  // Fertilizer & Nutrient Schedule
  fertilizer_plan: {
    is_soil_test_based: boolean;
    area_display: string; // e.g. "৩৩ শতক (১ বিঘা)"
    basal_dose: Array<{
      fertilizer_name_bn: string;
      fertilizer_name_en: string;
      amount_kg: number;
      application_time_bn: string;
      instruction_bn: string;
    }>;
    split_doses: Array<{
      split_number: number;
      fertilizer_name_bn: string;
      fertilizer_name_en: string;
      amount_kg: number;
      target_day_offset: number; // DAT
      target_date: string; // "YYYY-MM-DD"
      conditions_bn: string; // e.g. "জমি থেকে পানি কমিয়ে ছিপছিপে অবস্থায় সার দিন"
    }>;
  };

  // Risks, Cautions & Helpline
  risks_and_cautions: {
    disease_risks: Array<{
      disease_key: string;
      disease_name_bn: string;
      vulnerable_stage_bn: string;
      prevention_bn: string;
    }>;
    weather_risks_bn: string[];
    prohibited_actions_bn: string[];
    helpline_notice_bn: string;
  };

  // Farmer's Notes
  farmer_notes?: string;
}
```

## 3. Storage & Schema Migration

Plans are stored in IndexedDB under the database `"agroleaf"`, store name `"plans"`.
- **Primary Key:** `id` (string UUID).
- **Indices:**
  - `created_at`: For chronological sorting.
  - `variety_id`: For quick lookup by crop variety.
  - `season`: For seasonal filtering (`boro`, `aman`, `aus`).
- **Data Safety:** Local-first, privacy-safe, never uploaded to third-party tracking servers without explicit farmer consent.
